# Real time sentiment analysis of comments

This Python script simulates a real-time stream of comments and performs basic sentiment analysis on each comment as it arrives. It demonstrates how to process incoming data and extract sentiment in a near real-time fashion, akin to analyzing viewer reactions during a live stream.

## Language

`python`

## How to Run

Run the script using: python real_time_sentiment.py
